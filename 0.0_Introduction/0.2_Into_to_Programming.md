# What is Programming?

Programming is the process of writing logical and unambiguous instructions that tell a computer how to perform a specific task.

Programming is fundamentally about **problem-solving**.

Code is simply the language used to express the solution.

---

# Programming Starts with a Problem

Every program begins with a real-world problem.

Example:

**Problem:** Calculate the average marks of students.

Instead of solving it manually every time, we write a program that automates the calculation.

---

# Algorithm vs Program vs Software

## Algorithm

A step-by-step solution to a problem.

Example:

Making tea.

1. Boil water.
2. Add tea leaves.
3. Add milk.
4. Add sugar.
5. Serve.

---

## Program

An algorithm written in a programming language.

Example:

```python
marks = [80, 75, 90]
print(sum(marks) / len(marks))
```

---

## Software

A complete product that contains many programs along with databases, configurations, documentation, APIs, user interfaces, and other supporting components.

---

# Why Programming Languages Exist

Computers understand only machine instructions.

Programming languages allow humans to write solutions in a readable form, which are later translated into instructions the computer can execute.

---

---

# Compiler vs Interpreter

| Compiler                                       | Interpreter                  |
| ---------------------------------------------- | ---------------------------- |
| Translates the entire program before execution | Executes code line by line   |
| Produces executable files                      | Executes directly            |
| Faster after compilation                       | Easier to debug              |
| Examples: C, C++                               | Examples: Python, JavaScript |

**Note:** Python first compiles source code into bytecode before it is executed by the Python Virtual Machine (PVM).

# Key Takeaways

* Programming is a problem-solving process.
* Algorithms describe the solution, programs implement it, and software delivers it to users.
* Programming languages make communication with computers practical.
* Compilers and interpreters translate human-readable code into executable instructions in different ways.
* Python is a powerful and versatile programming language used across many domains.
