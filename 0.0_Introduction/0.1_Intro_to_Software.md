# Overview

Software is the intelligence that enables hardware to perform useful tasks. Every application we use today—from messaging apps to banking systems—is built with software. Understanding what software is and why it exists is the first step toward becoming a software engineer.

This module explores the fundamentals of software, its purpose, types, and its role in modern computing.

# What is Software?

Software is a collection of programs, data, and instructions that tell a computer how to perform specific tasks.

Unlike hardware, software cannot be physically touched. It provides the logic and intelligence that enables hardware to function.

**Simple Analogy**

* **Hardware** → Human Body
* **Software** → Human Brain

Both are required for a complete computing system.

---

# Hardware vs Software

| Hardware                | Software                            |
| ----------------------- | ----------------------------------- |
| Physical components     | Digital instructions                |
| Can be touched          | Cannot be touched                   |
| CPU, RAM, SSD           | Windows, Chrome, VS Code            |
| Manufactured            | Developed                           |
| Can wear out physically | Can become outdated or contain bugs |

# Why Does Software Exist?

Software exists to solve real-world problems.

Examples:

| Problem          | Software Solution |
| ---------------- | ----------------- |
| Communication    | WhatsApp          |
| Navigation       | Google Maps       |
| Online Shopping  | Amazon            |
| Video Streaming  | Netflix           |
| Digital Payments | Banking Apps      |

**Important Mindset**

Software development starts with identifying a problem—not choosing a programming language or framework.

---

# Types of Software

## 1. System Software

Manages hardware resources and provides a platform for applications.

Examples:

* Windows
* Linux
* macOS
* Android
* Device Drivers

---

## 2. Application Software

Designed to help users perform specific tasks.

Examples:

* Chrome
* VS Code
* Microsoft Word
* Spotify
* WhatsApp

---

## 3. Development Software

Used by developers to create software.

Examples:

* Python
* Java
* Git
* Docker
* Visual Studio Code
